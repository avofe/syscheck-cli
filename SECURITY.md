# Security Policy

## Reporting a Vulnerability

Если вы нашли уязвимость — НЕ создавайте публичный Issue.

Обрисуйте проблему одним из приватных способов:

- **GitHub Security Advisory** (рекомендуется):
  https://github.com/avofe/syscheck-cli/security/advisories/new
- **Email**: mazurenkoi70@gmail.com

В сообщении укажите:

- версию (`syscheck --version`),
- ОС и способ установки (pip / exe / из исходников),
- шаги воспроизведения,
- ожидаемое vs фактическое поведение.

### Регламент

- Подтверждение получения: в течение 48 часов.
- Публичный патч: стараемся в течение 14 дней, если возможно.
- После фикса публикуется security-advisory на GitHub и новая версия на PyPI.

## Безопасность `!shell`

Команда `!shell <cmd>` выполняет произвольные команды ОС прямо из TUI.

- По умолчанию **ВЫКЛЮЧЕНА**, включается только флагом `--enable-shell`.
- Каждая команда подтверждается отдельно.
- Каждое выполнение записывается в `~/.syscheck/shell_audit.log`.

Рекомендуется не включать `!shell` на машинах, где вы не единственный
пользователь.
